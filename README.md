# ☕ 대연마루 주문 앱

기쁜소식부산대연교회 **CAFE 대연마루**의 주문·주방·매출 관리 웹앱입니다.
설치 없이 링크만 열면 되고, 모든 기기가 같은 주문 데이터를 공유합니다.

👉 **https://lee-ship-jp.github.io/daeyeonmaru/**

## 화면 구성
| 탭 | 하는 일 |
|---|---|
| 📱 주문 | 손님 번호(1~30) 선택 → 메뉴 담기 → 주문 등록 |
| 🍳 주방 | 대기 중인 주문 확인 → 선택 → 완료 처리 |
| 📋 내역 | 날짜·상태·손님별 조회, 메뉴별 판매 집계, 매출 요약 |

## 메뉴
커피 / 라떼 / 에이드·주스 / 차 / 스무디·쉐이크 / 건강 스무디 / 디저트 / 옵션
— 총 38종. 메뉴 수정은 `index.html`의 `const MENU = [...]` 배열에서 합니다.

## 데이터 저장
주문은 구글 시트 **「대연마루 주문」**에 저장됩니다 (Google Apps Script 웹앱 경유).
각 기기는 화면이 켜져 있는 동안 약 4초마다 갱신합니다.
연결이 끊기면 그 기기에서만 저장되는 로컬 모드로 계속 동작합니다.

설정 방법은 [APPS_SCRIPT_SETUP.md](APPS_SCRIPT_SETUP.md) 참고.

## 파일
- `index.html` — 앱 전체 (단일 파일)
- `apps-script/Code.gs` — 구글 시트 백엔드 스크립트
- `APPS_SCRIPT_SETUP.md` — 클라우드 동기화 설정 가이드
